# Tier 1 (public-domain guideline ingestion) — DEFERRED 2026-06-04

Jenni decided not to pursue this. The 197 hand-curated society summaries in `index.html` `GUIDELINES` cover ~95% of what gets cited in IM teaching talks; bulk-ingesting USPSTF/CDC/NICE pages on top would be marginal value for the effort.

Both `auto_ingest_guidelines.mjs` and this file are kept for archival reference only — not in active use.

If you want to revisit later, the strategic framing was:
- Public-domain (USPSTF, CDC, NICE, WHO) = bulk-ingestible
- Copyrighted societies (AHA/ACC/KDIGO/etc) = hand-curated summaries (current approach, working well)
- FDA DailyMed = gap-filling drug labels only, never for newest indications
